# 规格：段落生命周期（core.StateMachine）
#
# 意图：把「说 → 看 → 落字」的时序，以及三条硬承诺钉住：
#   ① 取消（Esc）一个字都不注入；
#   ② 切窗口不丢话 —— 照常提交，只是**不自动发送**（DESIGN.md §7 原规则太狠，实测后改过）；
#   ③ 采集中断 / 提交超时**不会**把状态机永久卡住（0.9.4 修掉的两个"只能杀进程"死局）。
# 来源：DESIGN.md §2.2 / §2.3 / §7；docs/IMPLEMENTATION-STATUS.md §3.1 第 21 / 30 条；
#       docs/DECISIONS.md D2（出口诚实）与「A 批次」A-4。
#
# 语法（每行一个用例，用 | 分列；# 开头是注释，空行忽略）：
#   用例名 | 事件序列 | 终态 | onSegmentStartRequested 次数 | onCommitReady 次数 | ctx.inject | 结束原因 | 被忽略事件数
#   - 事件序列用 > 连接（名字取自 core.StateMachine.Event）
#   - "-" 表示该列不做断言
#
# 改动规程：**改本文件 = 改规格**。必须走 [SPEC] 提交，并在 docs/DECISIONS.md 记一条 ——
# 否则就是"为了让测试过而改期望值"，这份规格也就废了。
